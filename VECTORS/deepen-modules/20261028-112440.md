## Position

Two deepenings from an architecture review are done but not committed, on top of the earlier uncommitted subagent-queue work and the pi-bgtasks rename. All three sets of changes are mixed in the same files.

- New `src/jobs.ts`: the job ledger. It gives both lanes one lifecycle: the v1 stores and events, ids across lanes, settle (the first call wins, and a recorded kill keeps `killed`), kill, read/unread, pruning, and the footer counts.
- New `src/scheduler.ts`: a FIFO run scheduler (`submit` / `withdraw` / `waiting` / `setLimit`). Its state lives on globalThis and can adopt runs started outside the queue.
- `src/shell.ts` and `src/agents.ts` now only say how their work starts, stops, and is shown. `src/index.ts` calls `jobs.*`. `src/kit.ts` holds the one definition of `live` and `unread`. `src/host.ts` lost `count`, `taken`, and `stores`. `README.md` has a code map.
- Snapshot of the tree before the refactor: `refs/backup/pre-job-ledger` (a `git stash create` commit, not on any branch).
